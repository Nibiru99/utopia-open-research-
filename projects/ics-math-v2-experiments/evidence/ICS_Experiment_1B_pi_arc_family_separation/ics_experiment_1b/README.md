# ICS Experiment 1B Package

This package contains the π-arc family-separation tuning experiment for ICS-Math.

Files:
- experiment_1B_documentation.md — human-readable report
- experiment_1B_metrics.csv — metrics table
- experiment_1B_metrics.json — metrics as JSON
- experiment_1B_symbol_coordinates.csv — generated symbol coordinates
- experiment_1B.py — executable Python experiment script
- figures/ — visualization PNG files

Main conclusion:
B1 is the best coordinate-placement candidate for semantic family separation.
B2 proves mirror-pair geometry, but reduces family-neighborhood purity when the mirror is forced geometrically.
Recommended next step: use B1 coordinates plus B2-style mirror edges as graph metadata for Experiment 2.
