# ICS Experiment 2 — B3 Equation Encoding

This package contains the second ICS-Math validity experiment.

Main point:
- B3 = π-arc family-sector coordinates + mirror-pair graph metadata.
- Simple equations are encoded as fragment loops.
- The loops are decoded back into standard notation.
- No emotional, observer, CLO, PAM, MPIF, or value-dynamics symbols are introduced.
