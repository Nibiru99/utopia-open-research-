# Zenodo new-version checklist

## Identity and lineage

- [ ] Concept DOI and current version DOI recorded
- [ ] Current files and checksums frozen
- [ ] Creator is David Glowalla; ORCID/affiliation reviewed
- [ ] Version and changelog prepared
- [ ] Repository, release, and prior version linked

## Integrity and reproducibility

- [ ] Claim–evidence table reviewed
- [ ] Unsupported claims removed, withdrawn, or marked untested
- [ ] Confirmatory and exploratory analyses separated
- [ ] Negative results and deviations retained
- [ ] Exact commit/tag, environment, seeds, commands, outputs, and checksums recorded
- [ ] Licenses and third-party rights reviewed
- [ ] Human-data, privacy, and ethics gates addressed if applicable

## Publication control

- [ ] Files uploaded to a new-version draft
- [ ] Metadata and preview reviewed
- [ ] Draft remains unpublished until David Glowalla approves the exact package
