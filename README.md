# Utopia Open Research

Public release workspace for research software, reproducible benchmarks, and manuscripts by **David Glowalla**.

## Repository role

This is the publication-facing layer of the Utopia research archive, not a mirror of the private working vault.

- `projects/` contains bounded publication packages.
- `templates/` contains shared evidence and release controls.
- Scientific work enters through a project branch and draft pull request.
- Branches and draft PRs are provisional; tags and archived deposits identify releases.
- The private Codex Playground remains the internal evidence ledger.
