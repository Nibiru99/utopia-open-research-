# Public Research Map

## Repository Roles

| Repository | Public role |
| --- | --- |
| `utopia-open-research-` | Curated research maps, evidence summaries, and publication records |
| `ics-geo-tools-` | Reproducible ICS AP and GEO X experiment packages |
| `pam-benchmark-` | Public PAC/PAM benchmark definitions and result contracts |
| `pam-pac-core` | Private PAC/PAM implementation and integration work |
| `utopia-codex-playground` | Private project archive and development vault |

## Initial Public Lanes

### ICS AP

Certificate construction, boundary pressure, finite predicates, and explicit
transitions between empirical tables and analytic candidates.

### GEO X

Metric correction, explicit coupling, hidden-base recovery, adaptive schedule
controls, replication, and causal state-field-state experiments.

### PAM/PAC

Architecture summaries are published only when their linked implementations and
benchmarks have a stable version. Private cognition-loop development remains in
`pam-pac-core` until that gate is met.

## Publication Flow

```text
private source note or experiment
-> evidence and authorship review
-> reproducibility or citation check
-> public summary draft
-> repository review
-> publication
```

The publication queue records candidates without implying endorsement or a final
scientific conclusion.
